# Slutprojekt — Enkel webbplats

Jag har byggt en enkel webbplats med sidor för startsida, inloggning, registrering, profil och visning av aktier/produkter. JavaScript finns i `main/index.js` och stilmallar i `main/style.css`.

Krävs:
- Visual Studio Code
- Tillägget Live Server (VS Code)

Kör (snabbt):
1. Öppna projektmappen i VS Code.
2. Installera Live/five Server.
3. Högerklicka på index.html i main mappen → "Open with Live Server" eller klicka på "Go Live".
